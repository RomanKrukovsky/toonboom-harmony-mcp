# Бар: числа телевизионного конвейера

Референс для конвейера — не картинка, а измеримые цели. Скриншот не показывает ни
очереди, ни возобновления, ни сборки серии; эти шесть граней показывают.

Машина прогона: 14 ядер, 36 ГБ, Blender 5.1.1, ffmpeg/ffprobe в PATH.

## Объём одной серии (то, что должно пройти за ночь)

| величина | значение | откуда |
|---|---|---|
| длина серии | 22 мин | стандарт получасового ТВ-слота |
| кадров при 24 fps | **31 680** | 22 × 60 × 24 |
| шотов при средней длине 4.2 с | **≈314** | 31 680 / (4.2 × 24) |
| текущая скорость | 347 мс/кадр в 1 поток | измерено: 72 кадра за 25 с в smoke_full_shot |
| серия в один поток | **3.1 часа** | 31 680 × 0.347 с |

## Цели по граням

**throughput.** Серия считается за ночь. Цель: ≥ 8× ускорение против одного потока
на 14 ядрах (реалистично при накладных расходах на запуск Blender), то есть
**≥ 2.7 кадра/с** суммарно, серия ≤ 3.3 ч → **≤ 25 минут**.
Проверка: очередь из N шотов, замер стенных часов, сравнение с однопоточным временем.

**resilience.** Прогон переживает аварии, и это проверяется настоящей аварией, а не
рассуждением:
- `kill -9` посреди прогона → возобновление досчитывает ОСТАТОК, готовые шоты не
  пересчитываются;
- битый рисунок в одном шоте → этот шот падает, **остальные доходят**;
- нет места на диске / нет ffmpeg → внятная ошибка до начала счёта, не посреди.

**resume.** После падения на шоте k из N повторный запуск считает N−k+1 шотов, не N.
Проверка: убить, замерить, сравнить число посчитанных.

**assembly.** На выходе ОДИН мастер: видео + звук, длительность равна сумме шотов
±0.1 с, порядок шотов по раскадровке. Проверка: ffprobe длительности и потоков.

**traceability.** На любой кадр серии отвечается: какой шот, кто рисовал, какой сид,
чей стиль. Цепочка хэшей цела. Проверка: `frame_report` по случайным кадрам.

**operability.** Запускает человек, который не писал этот код: одна команда, понятный
прогресс, внятные ошибки с указанием, что делать. Проверка: сухой прогон по
собственной документации без чтения исходников.

## Чего в этом баре намеренно НЕТ

Визуального качества кадра. Оно есть в частях как ОДНА грань из шести и стоит
последним: конвейер, который делает красивый кадр и не может собрать серию, —
это провал, описанный в references/product.md.
