# traceability — на любой кадр серии: кто, чем, каким сидом

серия: 314 шотов × 100 кадров = **31400 кадров**, 690 записей в реестре

| требование бара | наше |
|---|---|
| отвечает на СЛУЧАЙНЫЙ кадр | **30/30** случайных кадров отвечены полностью |
| назван человек-автор | да, в каждом отвеченном |
| назван сид | да, в каждом отвеченном |
| назван стиль | да, где применялся |
| цепочка хэшей цела | да |
| правка записи ломает цепь | да (1 жалоб) |
| удаление записи ломает цепь | да (345 жалоб) |
| вставка записи ломает цепь | да (347 жалоб) |

## Цена на объёме серии

- запись 690 записей: 0.04 с
- проверка всей цепочки: **2 мс**
- ответ на один кадр: **0.0 мс** (среднее по 30)
- свод по серии: {"human": 0, "generated": 0, "mixed": 2000, "untracked": 0} (первые 2000 кадров)

## Всё по бару

Все 30 случайных кадров отвечены, три способа подделки обнаружены, проверка цепочки 2 мс.
