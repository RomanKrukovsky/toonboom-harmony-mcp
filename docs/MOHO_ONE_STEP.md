# Один шаг до живой связи с Moho

Всё остальное готово и проверено. Осталось одно действие в интерфейсе Moho,
которое нельзя сделать за тебя: macOS не разрешает программно нажимать кнопки
в чужих приложениях без разрешения, которое выдаётся только человеком.

## Что сделать

1. Moho уже запущена. Открой любой документ (или создай новый).
2. Открой меню **Scripts** в строке меню.
3. Выбери пункт **MohoMCP Server**. Рядом с ним появится зелёный значок.

## Проверка

```bash
node scripts/verify_moho_live.mjs
```

Скрипт сам скажет, получилось или нет. Если получилось — увидишь данные
документа, которые пришли из живой Moho.

## Почему именно это

Плагин опрашивает папку обмена изнутри Moho, из цикла перерисовки окна. Пока
опрос не включён, запросы просто копятся в папке и никто их не читает.

Отдельная тонкость, из-за которой перезапуск Moho не помогает: **Moho читает
файлы скриптов только когда человек раскроет меню Scripts**, а не при запуске.
Проверено фактом — время последнего чтения файла плагина совпадало с моментом
его установки и не менялось после перезапуска приложения.

## Как понять, что опрос работает

В папке `~/Library/Application Support/MohoMCP/ipc` появится файл
`health.json`. Его отсутствие — надёжный признак, что опрос не запущен.

```bash
cat ~/Library/Application\ Support/MohoMCP/ipc/health.json
```

## Если не помогло

Второй способ включить опрос — выбрать инструмент **MohoMCP Poller** на панели
инструментов. Он делает то же самое.

Если и это не сработало, запусти проверку и покажи мне вывод: скрипт различает
три разных исхода и назовёт, на каком шаге встало.
