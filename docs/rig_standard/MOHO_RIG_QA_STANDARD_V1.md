# MOHO_RIG_QA_STANDARD_V1

Критерии приёмки рига. Открытие файла и наличие костей — НЕ готовность.
Шкала: PASS / WARN / FAIL. Визуальный провал отменяет численный балл.

## 1. Структурная QA (авто, скриптом)

- [PASS] binding_mode=1 во всех скелетах. [стандарт 20/20]
- [PASS] у каждой части есть parent_bone ≥ 0 либо обоснование (весовая
  привязка внутри mesh).
- [PASS] имена диалов по схеме `<Система> Switch|Bend|Rol|Order|Squash`.
- [WARN] безымянные кости вне деформерных цепочек.
- [FAIL] кость-диал без actions-поз; свитч без состояний; диал с именем
  action, не совпадающим ни с одним свитчем (висячая связь).
- [FAIL] слои вне группы корня персонажа.

## 2. Деформационная QA (позы в Moho + взгляд)

Позы: нейтраль; локоть 0/45/90/135°; колено 0/45/90°; наклон Body ±20°;
поворот головы по всем 9 позам диала.
Проверять на каждой: силуэт, неразрывность сустава, сохранение объёма,
отсутствие щелей между частями, порядок слоёв.
- [FAIL] разрыв силуэта или вывернутый сустав на любой проверенной позе.
- [WARN] лёгкое сплющивание объёма при полном сгибе (если нет корректирующего
  диала — завести по правилу 12).

## 3. Лицевая QA

- Блинк: веко закрывает глаз полностью, не проходит сквозь зрачок.
- Зрачки: крайние положения диала не выходят за белок.
- Брови: 3 позы на каждом ракурсе головы.
- Рот: все состояния на всех ракурсах, где рот присутствует.
- [FAIL] лицо не переключилось вместе с видом головы (рассинхрон группы).

## 4. Комбинационная QA (ловит то, что одиночные тесты скрывают)

- поворот головы + блинк;
- поворот головы + улыбка;
- наклон корпуса + поднятая рука;
- согнутый локоть + поворот кисти;
- голова и корпус в противофазе;
- скрещивание ног (проверка Leg order).
- [FAIL] любой визуальный разрыв в комбинации.

## 5. Animator UX QA

- Каждый диал имеет говорящее имя и ограниченный constraints диапазон.
- Нейтраль диала = поза 0 = вид Front.
- Аниматор не должен трогать технические кости (деформеры, маски).
- [WARN] диал, диапазон которого выходит за полезные позы.

## 6. Балл качества (100)

| Категория | Баллы |
|---|---|
| Деформации (суставы, объём) | 20 |
| Лицо (глаза/брови/рот/челюсть) | 15 |
| Поворот головы | 15 |
| Тело/конечности (управляемость) | 10 |
| Смарт-диалы (полнота, имена, диапазоны) | 10 |
| UX аниматора | 10 |
| Порядок слоёв/переключения | 5 |
| Организация проекта | 5 |
| Редактируемость другим ригером | 5 |
| Отсутствие лишней сложности | 5 |

90+ продакшн; 80–89 сильно, требует ревью; 70–79 прототип; <70 не принимается.
Любой FAIL визуальной QA отменяет балл: риг возвращается.

## 7. Обязательный артефакт приёмки

Рендер-сетка проверочных поз (нейтраль + суставы + лицо + комбинации)
прикладывается к ригу. Риг без сетки не считается проверенным — независимо
от балла.
