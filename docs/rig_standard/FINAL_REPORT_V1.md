Дата: 2025-08-25. Набор: 20 ригов (fixtures/rig_library), форензика:
fixtures/rig_library/forensics/, PIR: pir/, каталог: _catalog.json.

## 1. Состав набора

Тяжёлые сериальные (Girl 297 костей, astronaft 639 слоёв, Dad body, Pioneer
Pesel, Litle girl, football_player), средние (Among, Normann, alien, Skelet,

## 2. Общая архитектура (паттерны большинства)

- binding_mode=1 везде; иерархия Main→Pelvis→Body→Neck/руки, Pelvis→ноги.
- Управление — диальные кости с actions-позами; связь диал→свитч по имени.
- Свитчи состояний: 2 (одежда) и 8–9 (виды головы) — доминанты.
- Маски швов — массово (до 104 на риг).
- Статичный z-order по глубине + диалы порядка.
- Кривые деформеры конечностей парами start/end.

## 3. Лучшие техники [E]

- Диальная система Girl: 36 именованных диалов, 43 связи, полный словарь
  `Switch/Bend/Rol/Order/Squash`.
- Head-turn: 9 поз, −45°..270°, карта Front/Back/1-4R/SideR/3-4R/Front/
  3-4L/SideL/1-4L (Girl=alien=astronaft=mannequin).
- start/end кривые деформеры конечностей (6 ригов).
- astronaft: 70 связей диал→свитч — максимум автоматизации состояний.
- mannequin: минимальный чистый скелет — лучший каркас для генерации.

## 10. Ограничения MCP (MohoMCP, факт на этой машине)

- Опрос моста ленивый: запросы обрабатываются только при перерисовке UI
  (нужна мышь во вьюпорте) — пакетные проверки медленны.
- document.screenshot с кастомными width/height роняет Moho 14.4
  (крэш FileRender00, отчёт 18:21). Использовать без размеров.
- В работающей копии моста (Documents/...) нет document.open/render/batch —
  открытие файлов только через Finder/пользователя.
- Рендер видео через мост недоступен в этой конфигурации.
- Из-за этого визуальные стресс-тесты (фаза 14) выполнены частично:
  ходьба Gramps принята пользователем в живой Moho; позы диалов головы
  отрендерить пакетно пока нечем — отмечено как долг.
