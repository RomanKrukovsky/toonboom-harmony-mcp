# MOHO_RIG_MODULE_LIBRARY_V1

Концептуальные модули для автосборки. Координаты и имена персонажей
не хардкодятся; геометрия берётся из входного персонажа, структура — отсюда.
Для каждого модуля: назначение, вход, структура, биндинг, контролы, валидация,
отказные режимы, референсы.

## ROOT_MODULE
- Назначение: единая точка перемещения/масштаба персонажа.
- Вход: центр таза персонажа.
- Кости: `Main` (корень, без родителя, constraints off).
- Контролы аниматора: перемещение/поворот Main.
- Валидация: перемещение Main двигает всё, ничего не отстаёт.
- Отказы: дочерние слои вне группы корня — отстают.
- Референсы: все 20.

## BODY_MODULE (Pelvis→Body→Neck)
- Назначение: корпус, наклоны, скрутка.
- Кости: `Pelvis` (вниз от таза), `Body` (таз→основание шеи),
  `Neck` (основание шеи→голова).
- Диалы: `Pelvis Switch` (9 поз у Girl), `Body Squash` (3 позы).
- Валидация: наклон Body не рвёт плечи и бёдра (маски швов).
- Референсы: Girl, Dad, Pioneer. [A]

## HEAD_MODULE + HEAD_TURN_MODULE
- Назначение: повороты/наклоны головы с подменой видов.
- Структура: SwitchLayer «Head» с состояниями видов внутри группы головы;
  диал `Head Switch` с 9 позами; каждый вид — свой набор лица.
- Стандарт диапазона: −45°..270°, шаг 45°. Карта Girl:
  `Front, Back, 1/4 R, Side R, 3/4 R, Front, 3/4 L, Side L, 1/4 L`.
- Дополнительно: `Head up` (взгляд вверх — дублирующий свитч с теми же
  видами), `Head Squash` (3–4 позы сжатия).
- Валидация: каждый из 8 видов + нейтраль; шов шеи закрыт маской/воротником.
- Отказы: промежутки между видами (использовать все 9 поз, не 5);
  рассинхрон лица и черепа (лицо внутри группы вида).
- Референсы: Girl, alien, astronaft, mannequin (идентичный диапазон). [E]

## EYE_MODULE / EYELID_MODULE / BROW_MODULE
- Диалы: `Eyes Switch` (3 позы), `Pupils Switch` (4), `Brows Switch` (3).
- Состояния зрачков: центр/влево/вправо (+вверх) — по ракурсам головы.
- Валидация: зрачки не выходят за белок на крайних диалах; брови на всех
  видах головы.
- Референсы: Girl, Dad. [A]

## MOUTH_MODULE
- Назначение: фоны/виземы с подменой по диалу и ракурсу.
- Структура: SwitchLayer «Mouth» на каждый ракурс головы (Girl: Front,
  3/4 L/R — отдельные рты); состояния 3–12 (astronaft 12).
- Диал: `Mouth Switch`.
- Валидация: рот на всех видах головы; стык с подбородком.
- Референсы: Girl, astronaft, Dad. [A]

## ARM_MODULE + ELBOW_CORRECTION_MODULE
- Кости: `UpperArm L/R → LowerArm L/R` (+кисть отдельно или свитчем).
- Органика: пары `X start`/`X end` — кривой деформер предплечья/плеча
  (Girl, Normann, alien, astronaft, mannequin, Test leg). [E]
- Диалы: `sort arm` (порядок рукав/рука), `Hands_r/L` (позы кисти).
- Валидация: локоть 0/45/90/135° — силуэт без складки-гармошки и разрыва.
- Отказы: жёсткая точечная привязка на длинном рычаге — рвёт локоть.

## HAND_MODULE
- Вариант по умолчанию: SwitchLayer кистей, 3–12 поз (Girl «hands» 12).
- Диал `Hands_r/L` выбирает позу; кисть крепится к концу LowerArm.
- Валидация: стык запястья на всех позах и ракурсах руки. [A]

## LEG_MODULE + KNEE_CORRECTION_MODULE + FOOT_MODULE
- Кости: `Thigh → Shin → Foot`; Foot — с диалами `Foot rol` (перекат
  стопы, 4 позы), `Foot Switch` (поза ступни), `Leg bend` (коррекция
  колена, 4 позы), `Leg order` (порядок ног при скрещивании, 3 позы).
- Валидация: колено 0/45/90°; перекат стопы пятка→носок; скрещивание ног
  меняет порядок без ручного вмешательства. [Girl: полный набор] [E]

## CLOTHING_MODULE (волосы/юбки/куртки)
- Диалы: `Skirt` (4), `jacket` (3), `sleeve down` свитчи (2 состояния).
- Динамика костей выборочно на волосах/юбке.
- Валидация: одежда следует за телом на наклонах, швы скрыты масками.
- Референсы: Girl, Dad, Pioneer. [B]

## Z_ORDER_MODULE
- Статичный порядок по глубине + диалы порядка (`Leg order`, `sort arm`,
  `up - midl - down L/R`) для переключений.
- Запрещено: ручное дублирование слоёв ради порядка. [A]

## MASK_MODULE
- Маска на швах: плечо, шея, таз, пересечения конечностей.
- Объём по эталонам: 8–104 масок на риг; тяжёлые риги 50–104.
- Валидация: на крайних позах швов не видно. [A]
