# MOUTH_AND_FACE_STANDARD_V1 — как на самом деле устроены профессиональные рты

Выведено из 7 источников: anim_ref.moho (канон Moho), Girl, astronaft, Dad body,
Mr.Stu, Litle girl, mouth_switch.moho (туториал). Не копирование — принципы.

## 1. Алфавит состояний = фонемы Moho

Канон (anim_ref.moho, 23 состояния): `A B C D E F G I K L M N O P Q R S T U V W TH Closed`.

Почему именно эти имена: встроенный липсинк Moho анализирует аудио и сам
расставляет ключи на свитче по ИМЕНАМ состояний. Назвал состояния фонемами —
получил автоматическую озвучку губ бесплатно. Произвольные имена
('Moutch 5' у astronaft) ломают автолипсинк: аниматор крутит всё вручную.

Компактный продакшн-сет (виземное сокращение): `Closed A E I O U F L MBP WQ`.

Наблюдение по эталонам: Girl использует `moutch A I O`, Dad — 3 нумерованных,
astronaft — 9 нумерованных, Mr.Stu — 11 нумерованных мешей. Живые ригеры часто
НЕ связываются с автолипсинком; канонический сет в библиотеке один (anim_ref).

## 2. Рот существует только там, где виден

- Girl: рот только в Front, 3/4 R, 3/4 L (3 вида из 8). На Side/Back рта нет.
- Dad/astronaft: 5 видов с лицом.
- Правило: лицо собирается ПО ВИДАМ, а не глобально. Каждый вид головы —
  группа: череп + те фичи лица, что видны в этом ракурсе.

## 3. Один диал двигает все виды сразу

У Girl диал `Mouth Switch` привязан одним именем экшена к трём разным свитчам
(Moutch/Moutch 2/Moutch 3 в разных видах). Поворот диала синхронно меняет рот
во всех ракурсах. Механизм — связь по имени экшена (см. PRODUCTION_RIG_STANDARD).

То же для глаз (Eyes Switch → 5 свитчей) и бровей (Brows Switch → 5).

## 4. Иерархия лица

```
Head (switch, 8 видов)
├── Front (group)
│   ├── череп (image/mesh)
│   ├── brows (switch × 3)
│   ├── eyes (switch × 8)      ← Girl: 8 состояний глаз
│   └── Moutch (switch × 4)    ← фонемы/виземы
├── 3/4 R (group): череп + brows + eyes + Moutch
├── Side R (group): череп + brows + eyes       ← без рта? нет: у Girl Side без рта
└── Back (group): только череп
```

Порядок внутри вида: брови → глаза → рот (рот поверх всего, ближе к зрителю).

## 5. Якоря и маски

- Состояния рта выравниваются по углу рта/губной кайме — угол закрытого рта
  совпадает с центром открытого, иначе виземы «прыгают».
- Профильные виды: Dad закрывает стык челюсти маской (`Head + moutch mack`).
  Маска принадлежит виду, не рту.
- Глаза Girl: 8 состояний (закрытые + направления взгляда) — зрачок рисуется
  в состоянии, не двигается отдельно (в этом классе ригов).

## 6. Рецепт генератора (реализовано в riggen)

Спецификация:
```json
"head_turn": {
  "states": {"Front": "...", "3/4 R": "...", ...},
  "face": {
    "mouth": {"views": ["Front", "3/4 R", "3/4 L"],
              "states": {"Closed": "...", "A": "...", "O": "..."},
              "center_by_state": {...}}
  }
}
```
Генератор строит: группы-виды → свитчи фич внутри нужных видов → ОДИН общий
диал на модуль лица (Mouth/Eyes/Brows) → связи по имени экшена. Диапазоны
диалов: mouth ±60°, eyes ±60°, brows ±40° (по умолчанию).

Проверено: modules_demo.moho — рот живёт во Front-виде, Back без рта,
Mouth Dial ↔ Mouth Switch связь выживает round-trip.
